\# ColorSwitcher (Лабораторная работа №3)



Приложение на Qt Widgets, демонстрирующее продвинутую работу с таймерами (`QTimer`), лямбда-слотами, обработкой событий мыши и динамическим управлением соединениями сигналов и слотов (`QMetaObject::Connection`).



\## 📌 Цель работы

Освоить класс `QTimer` для периодического выполнения кода, научиться использовать лямбда-функции в качестве слотов с корректным захватом контекста, а также создавать, разрывать и переподключать соединения между сигналами и слотами динамически, во время выполнения программы.



\## ⚙️ Возможности программы

1\. \*\*Управление таймером:\*\* Запуск и остановка таймера, изменение интервала срабатывания (от 50 до 5000 мс).

2\. \*\*Три режима работы таймера:\*\*

&#x20;  - \*Цикл:\* последовательный перебор цветов из палитры.

&#x20;  - \*Случайный:\* выбор случайного цвета из палитры.

&#x20;  - \*Мигание:\* переключение между текущим цветом и черным.

3\. \*\*Обработка мыши (События):\*\* Левый клик по холсту переключает цвет вперед, правый — назад (переопределен `mousePressEvent`).

4\. \*\*Динамическое переподключение (Context):\*\* Переключатель меняет обработчик сигнала `colorChanged` на лету (в одном режиме меняется статус-строка, в другом — заголовок окна).

5\. \*\*Динамические соединения:\*\* Кнопки-цвета создаются в рантайме. Для каждой кнопки создается `QMetaObject::Connection`, который сохраняется в список.

6\. \*\*Безопасная очистка:\*\* При очистке палитры все динамические соединения явно разрываются (`disconnect`), а сами кнопки удаляются через `deleteLater()`.



\## 🛠 Требования

\- Qt 5.x или Qt 6.x (модуль Widgets)

\- Компилятор C++17

\- qmake
